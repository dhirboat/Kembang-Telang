# Kembang Telang Garden Cafe Website

A promotional website developed for Kembang Telang Garden Cafe, a garden-themed cafe in Tangerang, Indonesia. The website is designed to provide visitors with essential information about the cafe, including its menu, atmosphere, location, reservation details, and contact information.

## Features

- Home page introducing the cafe and its concept
- Menu showcase featuring food and beverage offerings
- Gallery section displaying the cafe's atmosphere
- Reservation information for visitors
- Google Maps integration for easy navigation
- Contact information and social media access

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript
- jQuery

## Purpose

This project was created to improve the cafe's online presence and provide customers with an accessible platform to explore the cafe's offerings before visiting.
